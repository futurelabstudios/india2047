# Contributing to India2047

Thank you for imagining India's future with us. There are three ways to contribute.

## 1. Pitch an idea (no coding)

Open an issue using the **"Imagine a 2047 solution"** template. A maintainer will help turn good pitches into solution files.

## 2. Add a solution

1. Fork the repo and create a branch: `git checkout -b solution/<short-name>`.
2. Copy `solutions/_TEMPLATE.md` to `solutions/<theme>-<short-name>.md` (lowercase, hyphens, e.g. `water-village-rain-banks.md`).
3. Fill in every section. Keep it under ~800 words.
4. Open a pull request titled `Solution: <your title>`.

**What makes a good solution**

- Starts from a real problem people in India face today.
- Paints a concrete picture of 2047 — what a person's day looks like.
- Explains the path: the steps, policies, technologies or habits that got us there.
- Ends with a first step someone could take this year.
- Credits sources for any facts or figures. Don't invent statistics.

## 3. Improve the platform

Bug fixes, docs, translations and the upcoming web gallery are all welcome. Open an issue first for larger changes so we can agree on the approach.

## Review process

Maintainers review pull requests on a rolling basis. We may suggest edits for clarity, tone or accuracy. Content that is hateful, promotional, plagiarised or targets individuals will not be merged.
