# India2047

**Imagine India at 100. Then help build it.**

In 2047, India turns 100 as an independent nation. India2047 is an open-source platform where anyone — students, citizens, builders, researchers, artists — imagines how India has solved its biggest challenges by then, and shares those solutions openly with the world.

Every idea is public. Every idea can be remixed. The best ones become blueprints others can build on.

## What you'll find here

| Folder | What it holds |
| --- | --- |
| [`solutions/`](solutions/) | Imagined solutions for India in 2047, one Markdown file each |
| [`solutions/_TEMPLATE.md`](solutions/_TEMPLATE.md) | The template for writing a new solution |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | A form to pitch an idea without writing any code |

## Themes

Health · Education · Climate & Energy · Cities & Mobility · Agriculture & Food · Water · Governance · Jobs & Economy · Culture & Languages · Science & Space

## Share your imagination

**No coding needed:** open a new issue with the **"Imagine a 2047 solution"** template and describe your idea.

**Want to add it directly:**

1. Fork this repository.
2. Copy `solutions/_TEMPLATE.md` to `solutions/<theme>-<short-name>.md`.
3. Fill it in: the problem today, what India looks like in 2047, how we got there, and the first step anyone could take now.
4. Open a pull request.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full guide. Ideas in any Indian language are welcome.
