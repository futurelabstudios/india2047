# Security Policy

India2047 accepts public submissions and community code, so we take security seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**.

Include what you found, steps to reproduce, and the possible impact. We aim to acknowledge reports within 5 working days and will keep you updated until it is resolved.

## Supported versions

Only the latest version on the `main` branch is supported.
